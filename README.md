# 6×6 Tic Tac Toe

A responsive, two-player Tic-Tac-Toe game built with plain HTML, CSS, and JavaScript.

## Rules
- Play on a 6 × 6 grid.
- Players take turns placing X and O.
- Get 4 consecutive symbols horizontally, vertically, or diagonally to win.
- If all 36 cells are filled without a winner, the round is a draw.

## Play locally
1. Clone or download this repository.
2. Open `index.html` in any modern browser.

## Features
- 6 × 6 responsive game board
- Two-player X and O gameplay
- Four-in-a-row win detection in all directions
- Automatic draw detection
- Score tracking across rounds
- Restart round and reset scores controls
- Keyboard-accessible controls

No build tools or dependencies are required.
